# neolith-rs

The Rust rebuild of the Neolith map UI, as specified in [`DESIGN.md`](DESIGN.md): one codebase for the
native desktop app and the web (WASM) app, drawing the world as a 3D game board.

```
crates/core      headless data model: grid math, timelines, world, edits, world.bin   (no UI deps)
crates/convert   neolith-convert: combined_map.geojson + settlements.geojson <-> world.bin, stats
crates/app       the eframe/egui app with the wgpu board renderer (binary: `neolith`)
assets/world.bin generated by neolith-convert, checked in (19 KB)
```

## Run

```sh
cargo run --release -p neolith-app              # native; loads assets/world.bin
cargo run --release -p neolith-app -- my.bin    # or a world file of your choice

trunk serve                                     # web, dev server (needs `cargo install trunk`)
trunk build --release                           # static site in dist/ (index.html + .wasm + world.bin)
```

The web build uses WebGPU where the browser has it and WebGL2 otherwise.

## Data

`assets/world.bin` is built by the hex-map pipeline in the parent repo
(`../pipeline/README.md`). It draws the hand-drawn keyframe maps with
100-year fronts between them, plus sea level:

```sh
make -C .. maps                    # raw/ -> ../build/combined_map.geojson -> assets/world.bin
cargo run --release -p neolith-convert -- --stats assets/world.bin
cargo run --release -p neolith-convert -- --to-geojson assets/world.bin -o combined_map.geojson \
    --settlements-out settlements.geojson
```

`world.bin` is a 6-byte header (`NEOL` + version) followed by zstd-compressed postcard.

## Controls

| | |
|---|---|
| Left-drag | grab and move the board (Select / Fill tools, and Game mode) |
| Right-drag, Ctrl-drag | orbit and tilt |
| Middle-drag | move the board with any tool |
| Wheel / pinch | zoom towards the cursor |
| Double-click | glide to a hex |
| Space | play / pause (Game mode) |
| Ctrl/Cmd-Z, Shift-Ctrl/Cmd-Z | undo, redo (Editor mode) |

Editor tools: **Select** (Shift-click adds), **Pencil** (a drag is one undo step), **Fill**, **Lasso**
(Shift adds, Alt removes). Edits change the keyframe in effect at the current year, or create one at the
current year when "Insert keyframe at current year" is on.

## Test

```sh
cargo test --workspace
```

The `convert` tests read the real dataset (`../build/combined_map.geojson` from `make maps`, and
`../data/settlements/settlements.geojson`) and are skipped (with a note) if it is absent.

## Screenshots without a window

```sh
cargo run -p neolith-app -- --screenshot board.png --year -9000 --mode koeppen --pitch 35 --dist 1.2
cargo run -p neolith-app -- --screenshot flat.png --flat 1 --lip --material slate
cargo run -p neolith-app -- --ui-screenshot ui.png --editor     # opens the window briefly
```

`neolith --help` lists every option. These exist for comparing board styles side by side (DESIGN.md §11.3).
