# Settlement coordinate corrections

`data/settlements/corrections.toml` holds hand fixes to settlement positions;
the map build applies them to the shipped settlements before anything reads a
position (`pipeline/coords.py`). `SOURCES.md` here is generated by
`make settlements`, so the sources for the fixes are listed in this file instead.
`pipeline/tests/test_sources.py` checks that every fix has a link and that the
link is listed here.

Sites still suspect after the fixes are in `coordinate_audit.csv`, written by
each map build: `at_sea` (ground deep below sea level on a Water hex, or lower
than any dry land in the box), `offshore` (on Water with no land neighbour,
with the site's ground under the water), `same_name_far` (another site of the
same name more than 25 km away) and `hint` (a sign-flipped or swapped position
on dry land; only a hint).
